## Status vocabulary

- **CLOSED_NEGATIVE / CLOSED_BOUNDARY:** current version has a defensible bounded terminal result; publication packaging or new preregistered successor is a different task.
- **RESEARCH_BLOCKED:** cannot proceed without a named evidence, reviewer, license, dataset, or protected-access gate.
- **ENGINEERING_REVIEW:** new code exists but is not evidence of scientific efficacy; review/CI is required.
- **PROSPECTIVE:** new idea or study not yet frozen or authorized to generate outcomes.
- **UNVERIFIED:** identity, claim, publication or implementation status requires a fresh repo/source audit; avoid inventing success.
