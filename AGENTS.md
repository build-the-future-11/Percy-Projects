# Research session entry point

Read `RESEARCH_STATE.json` and its referenced truth, protocol, and development
records before research or engineering work. This is the repository index;
individual studies keep their own immutable protocol and evidence identities.

Before finishing, update the canonical index with the actual source revision,
changes, verification, failures, decisions, boundaries, and next executable
action. Append new dated records; preserve earlier records and Git history.
Do not replace an adverse result with a newer favorable interpretation.

A test pass is engineering evidence. It does not qualify novelty, validate a
scientific hypothesis, release protected data, or mark a project complete.
Record material scientific changes as successor hypotheses with a new protocol.
Respect existing frozen protocols and session authorizations; record uncertainty
where prior history or scientific qualification has not been audited.
